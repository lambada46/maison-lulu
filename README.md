# Maison Lulu

Traiteur événementiel à Avignon — *Bien recevoir, simplement.*

Site Next.js en français. Identité visuelle : vert olive, ivoire, sauge, terre cuite.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000.

## Vérification

```bash
npm run lint
npm run build
```

Les photos, coordonnées, tarifs et mentions légales doivent être validés avant publication. Les tarifs actuellement affichés sont des hypothèses commerciales.
